# Security Policy

## Supported Versions

The following versions of the VC Weather Widget Shopify app are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Security Vulnerability

If you discover a security vulnerability in the VC Weather Widget Shopify app or its backend service at `apps.visualcrossing.com/shopify`, please report it **responsibly and privately** — do not file a public GitHub issue.

**Contact:** Please email security concerns to the developer via the support contact listed on the [Shopify App Store listing](https://apps.shopify.com/) for this app.

## What to Include in Your Report

To help us resolve the issue quickly, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact (e.g. data exposure, widget manipulation, API key leakage)
- Your contact details for follow-up

## Response Timeline

- **Acknowledgement:** Within 48 hours of receiving your report
- **Assessment:** Within 5 business days
- **Resolution target:** Within 14 business days for confirmed vulnerabilities

## Scope

This security policy applies to:

- The `vc-weather-widget` Shopify theme app extension
- The backend proxy service at `apps.visualcrossing.com/shopify`
- The app configuration and GDPR webhook endpoints

## Out of Scope

- Vulnerabilities in the Visual Crossing Weather API itself (report those to [Visual Crossing](https://www.visualcrossing.com/))
- Vulnerabilities in Shopify's core platform (report those to [Shopify's bug bounty program](https://hackerone.com/shopify))
- Social engineering attacks
